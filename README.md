# Automatic Solar Tracking System

## Project Overview
An Arduino-based solar tracking system designed to adjust the solar panel's position according to sunlight intensity to improve the amount of sunlight received.

## Objectives
- Detect sunlight intensity using light sensors.
- Automatically adjust the solar panel's direction.
- Improve solar energy capture compared with a fixed-position panel under suitable conditions.

## Components
- Arduino board
- Light-dependent resistors (LDRs)
- Servo motor or geared motor
- Solar panel
- Motor driver (if required)
- Connecting wires and power supply

## Working Principle
The light sensors detect differences in sunlight intensity. The Arduino processes the sensor readings and controls the motor to move the panel toward the brighter direction. This process repeats as sunlight direction changes.
